# Skill Swap - Ethan Shimmel

Skill Swap is a student-focused website where people are able to share their skills, discover new things to learn, and connect with others who are looking to teach or learn.

## Purpose

The goals of SKill Swap is to make it easier for students to find learning oppurtunities and share knowledge with others.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Features

- Homepage with navigation
- Browse  available skills
- Skill card with description, prices, and providers
- Interactive buttons to show additional information

## Project Status

This project is being developed as part of a course assignment to practice frontend development and professional Git workflows.
